# Innovate @ DIAB

We're the Hack Club at Dubai International Academy Al Barsha. Every week we pick something to build, argue about how to build it, and ship it. Websites, games, code, and hardware with real circuit boards in it.

You don't need any experience. Most of us started with none.

## When we meet

Wednesday or Monday at lunch. We email the exact day on Outlook each week.

## About Hack Club

[Hack Club](https://hackclub.com) is a nonprofit network of high school coding clubs around the world, run by students. Nobody hands you a syllabus. You build what you want to build.
